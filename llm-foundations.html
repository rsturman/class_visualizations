How LLMs Generate a Response

Follow your prompt through a large language model step by step — from raw text to the words appearing on your screen.

1 Tokenize → 2 Embed → 3 Attend → 4–5 Predict → 6 Sample → 7–8 Output
1 Tokenization

Your text becomes tokens

The model breaks your prompt into smaller pieces called tokens — roughly word-sized chunks, subword fragments, or punctuation marks. Each token is mapped to a number using a fixed vocabulary. This converts human-readable text into a sequence of numbers the model can work with.

2 Embedding

Each token gets a position in meaning-space

Each token number is converted into a vector — a long list of values that represents what that token means. Tokens with similar meanings end up with similar vectors. At this stage, each token's meaning is context-free: the model doesn't yet know how the words relate to each other in this particular sentence.

3 Attention

The model reads context through attention

The model examines all tokens at once and calculates how each one relates to every other one. This is called attention — each token "pays attention to" (or "attends to") the other tokens to understand their relationships. This happens across many transformer layers — think of them as repeated rounds of processing, each one refining the model's understanding. Early layers capture grammar and word proximity; later layers capture intent, topic, and meaning.

⚠ Constraint

The context window limits what the model can see

Steps 1–3 all happen within a fixed-size context window — the maximum number of tokens the model can process at once. Everything outside this window is invisible. This is a fundamental constraint that shapes what the model can understand and respond to.

4–5 Predict & Repeat

Next-token prediction and the coherence loop

After attention has built context-aware representations of every token, the model uses them to predict what comes next — one token at a time.

Step 4: Next-token prediction

Using the context-aware representations from Step 3, the model generates a probability score for every token in its vocabulary (~100,000 possibilities). It selects one (more on how in Step 6), appends it to the sequence, and repeats. Steps 3 and 4 run again — the model reprocesses the entire sequence each time to predict the next token. The response is built one token at a time, left to right.

Step 5: Coherence through the loop

There is no separate quality-check or editorial step. Coherence emerges because each prediction is based on the entire sequence so far — the original prompt plus every token generated up to that point. The model stays on topic not by reviewing its work, but because the full context steers each prediction.

Think of it like writing a sentence word by word: each word you choose is influenced by everything you've already written. The model does the same thing, but statistically across billions of learned patterns.

6 Sampling

How the model chooses the next token

The model doesn't always select the highest-probability token. Three controls shape the selection: temperature, Top-K, and Top-P. This is why the same prompt can yield slightly different responses each time.

Prompt: "The cat sat on the …"
Temperature

Reshapes the distribution. Low values sharpen it (confident, repetitive). High values flatten it (creative, chaotic). Acts on all tokens.

Top-K

Keeps only the K most likely tokens and discards the rest. Simple hard cutoff. K=5 means only 5 candidates survive.

Top-P

Keeps the smallest set of tokens whose combined probability ≥ P. Adapts dynamically — sometimes 3 tokens, sometimes 8, depending on how confident the model is.

7–8 Output

Detokenization and delivery

The model's internal work is done. Now the numbers need to become words on your screen.

Step 7: Detokenization

Each generated token is still a number. The model reverses the lookup table from Step 1, converting token IDs back into text fragments and reassembling subword pieces into complete words. For example, token IDs [30729, 38, 11571] become the fragments ["Chat", "G", "PT"], which are joined to produce "ChatGPT".

Step 8: Output delivery

The detokenized text is streamed to your screen token by token as it is generated — this is why responses often appear word by word in real time. The model doesn't compose the full response and then send it; it sends each piece as soon as it's produced. What you see appearing on screen is the model thinking in real time.
